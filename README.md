# Student Marks Analysis

## Description

This project is a simple Python program that analyzes student marks.

The program calculates:

- Total marks
- Average marks
- Highest mark
- Lowest mark

## Objective

The objective of this project is to practice Python data processing
and basic statistical calculations.

## Tools Used

- Python
- Jupyter Notebook
- Visual Studio Code

The project uses manually created student marks.
